# gestionnaire-de-contact-
realisation d'un gestionnaire de contact
cet exercice consiste a creer un gestionnaire de contact permettant d'ajouter et de rechercher le contact par son nom 
dans cet exercice l'utilisateur n'aura qu'a rentrer le nom d'une personne et le numero s'affichera 
pour le faire j'ai utilisé des methodes , des attributs, des objets, des constructeurs
j'ai eu à utiliser trois classes :
.CntactatsManager
.Contact 
.Main : qui appel la methode creer dans CntactatsManager
